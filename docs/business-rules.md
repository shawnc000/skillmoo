# Business rules

These invariants protect the credibility of the public SkillMOO engine.

1. Static grade is not runtime efficacy. Never invent or generalize an effectiveness claim from static analysis.
2. Capability is not malicious intent. Legitimate key, network, file, or shell use may require review; a block requires a real malicious signal.
3. Grade and safety gate are separate. Evidence scope must state whether only `SKILL.md` or the full bundle was analyzed.
4. Optimization is verify-or-reject and must never silently write user Skill files or worsen protected invariants.
5. CLI analysis is deterministic and locally auditable. Any optional network behavior must be explicit, content-minimized, and disableable.
6. Ratings are never for sale. Commercial hosted features must not alter the static score.
7. The executable rubric constants are authoritative. Public methodology must remain coupled through `eval:methodology`.
8. Private gold labels, efficacy answer keys, accumulated outcome data, credentials, hosted services, and strategy are outside this public repository.
9. A shared-engine change is incomplete until the intended private/public parity and package-version consequences are documented and tested.
